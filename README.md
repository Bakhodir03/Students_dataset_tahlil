# Students Dataset Analysis

## About the Project

This project analyzes a student dataset using Python.

The analysis focuses on student characteristics and different factors that may be related to exam scores. The project includes data exploration and several visualizations.

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset is stored in `students.csv`.

It contains information about students such as:

- Gender
- Age
- Parental education level
- Extracurricular participation
- Study hours per day
- Part-time job
- Diet quality
- Internet quality
- Exam score

## Analysis

The project includes:

- Viewing the first rows of the dataset
- Checking column names
- Checking dataset dimensions
- Gender distribution
- Age distribution
- Parental education level
- Extracurricular activity participation
- Study hours and exam score
- Part-time job and exam score
- Diet quality and exam score
- Internet quality and exam score

## Visualizations

The generated charts are stored in the `results/` folder.

Examples include:

- Gender distribution
- Age distribution
- Parental education level
- Extracurricular participation
- Study hours vs exam score
- Part-time job vs exam score
- Diet quality vs exam score
- Internet quality vs exam score
